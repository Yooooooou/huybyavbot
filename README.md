# memebot — «Мемный вырезчик»

Телеграм-бот, который в случайные моменты времени берёт мемный ролик с YouTube,
вырезает случайный короткий отрезок аудио (5–15 сек) и отправляет его в чат как
**голосовое сообщение**. Повторы одного и того же отрезка исключаются. Бот работает
сам по расписанию — пользовательских команд нет.

## ⚠️ Дисклеймер (честно, не прячу)

Скачивание аудио с YouTube технически **нарушает ToS YouTube**. Для приватного бота
в узком кругу друзей на практике это не отслеживается и риска почти нет, но это **не
«белая» схема**. Если хочется на 100% чисто — см. раздел «Альтернатива без YouTube»
ниже (TTS + собственные SFX, никакой привязки к чужому видео).

## Как это работает

1. `sources.json` — курируемый вручную список YouTube video ID (мем-звуки, подборки).
2. По расписанию (APScheduler, случайный интервал) бот берёт случайный ID.
3. `yt-dlp` качает только аудиодорожку во временную папку.
4. `ffprobe` узнаёт длительность, выбирается случайная стартовая точка (не первые/
   последние 5 сек), `ffmpeg` вырезает отрезок 5–15 сек.
5. Отрезок конвертируется в формат голосового Telegram (OGG/Opus, моно, 48 кГц).
6. Отправка через `bot.send_voice(...)`.
7. В `sent_log.json` пишется только `{"video_id", "start_sec"}` — для дедупликации.
   Сам аудиофайл **не хранится**: временная папка удаляется сразу после отправки.

Дедупликация: если пара `(video_id, start_sec ±3 сек)` уже была — выбирается другая
точка или другое видео.

## Установка

```bash
pip install -r requirements.txt
```

Требуется **ffmpeg** (с `ffprobe`) в системе:

```bash
# Debian/Ubuntu
sudo apt install ffmpeg
# macOS
brew install ffmpeg
```

## Настройка

```bash
cp .env.example .env
```

Заполни `.env`:

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather).
- `CHAT_ID` — id чата. Для группы: добавь бота в группу и возьми отрицательный id
  (напр. `-1001234567890`). Для лички — свой user id.

Необязательные параметры (интервал, тихие часы, длина клипа, тест-отправка при старте)
описаны в `.env.example`.

## Наполнение sources.json

Открой `sources.json` и вставь 20–50 video ID мемных подборок. ID — это часть ссылки
после `v=`: для `https://www.youtube.com/watch?v=dQw4w9WgXcQ` id = `dQw4w9WgXcQ`.
Три записи в файле — заглушки-примеры, замени их своими.

## Запуск

```bash
python bot.py
```

Для быстрой проверки поставь в `.env` `SEND_ON_STARTUP=true` — бот отправит один клип
сразу при старте.

## Деплой на Railway

- `nixpacks.toml` уже добавляет `ffmpeg` в окружение.
- Задай переменные окружения (`BOT_TOKEN`, `CHAT_ID` и опциональные) в настройках
  проекта Railway.
- Процесс запускается как worker (`Procfile`).

## Реалистичные ограничения

- **yt-dlp может периодически ломаться** из-за изменений на стороне YouTube. Лечится
  обновлением: `pip install -U yt-dlp`.
- **Прод-сеть.** Если Railway (или другой хостинг) режет/блокирует исходящий трафик к
  YouTube, скачивание в проде может не работать — проверяй на этапе деплоя.
- YouTube иногда требует авторизацию/куки для скачивания. При таких ошибках можно
  подсунуть `yt-dlp` cookie-файл (см. документацию yt-dlp).

## Альтернатива без YouTube (100% «чисто»)

Вместо вырезки — генерировать мем-звук самому: банк фраз (`phrases.json`) → TTS
(например Silero TTS, бесплатный локальный, хорошо с русским) → наложить заготовленный
SFX (смех, «bruh», airhorn из freesound.org) через `pydub`. Больше работы на старте,
но полностью снимает вопрос авторских прав. В текущей версии не реализовано.

## Структура

```
bot.py            # планировщик + основной цикл + дедуп
youtube_utils.py  # список источников + скачивание через yt-dlp
audio_utils.py    # ffprobe/ffmpeg: нарезка и конвертация в voice
sources.json      # список video_id (заполнить вручную)
sent_log.json     # лог отправленных фрагментов (создаётся автоматически)
requirements.txt
.env.example
nixpacks.toml     # ffmpeg для Railway
Procfile
```
